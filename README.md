<h1>Sobre o Projeto</h1>

<p style="text-align: justify">
  Este aplicativo inovador, construído com React Native e Node.js, utiliza a inteligência artificial do Gemini AI para gerar dietas personalizadas de forma rápida e eficiente.
</p>

<p style="text-align: justify">
  Com ele, você pode criar um plano alimentar adaptado às suas necessidades individuais, levando em conta informações como sexo, objetivo (emagrecer, hipertrofia, etc.), nível de atividade física, entre outros. O sistema consulta a IA do Gemini para elaborar refeições e até recomendar suplementos, tudo de forma prática e eficiente.
</p>

<ul style="text-align: justify">
  <li><b>Personalização Completa:</b> Crie dietas sob medida, considerando suas necessidades e objetivos.</li>
  <li><b>Inteligência Artificial:</b> Conte com a força da IA do Gemini para gerar planos alimentares otimizados.</li>
  <li><b>Praticidade:</b> Acesse sua dieta personalizada a qualquer hora e lugar, diretamente no seu smartphone.</li>
  <li><b>Compartilhamento Facilitado:</b> Compartilhe sua dieta com amigos e familiares para motivá-los a alcançar seus objetivos.</li>
</ul>

<br>

<h1>Tecnologias</h1>

<p>O aplicativo foi desenvolvido utilizando as seguintes tecnologias:</p>

<ul>
  <li><b>Frontend:</b> React Native;</li>
  <li><b>Backend:</b> Node.js;</li>
  <li><b>IA:</b> Gemini AI;</li>
  <li><b>Validação de Dados:</b> Zod;</li>
  <li><b>Formulários Reativos:</b> react-hook-form.</li>
</ul>

<br>

<h1>Como Executar o Projeto Localmente</h1>

<p>Para iniciar o backend e o frontend do aplicativo, siga os seguintes passos:</p>

**Instale as dependências:**

```bash
npm install
```

Inicie o backend:

```bash
npm run dev
```

Inicie o aplicativo mobile:

```Bash
npx expo start
```
